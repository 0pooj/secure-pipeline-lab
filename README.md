# Secure Pipeline Lab (DevSecOps) 🛡️

This project demonstrates a basic DevSecOps Pipeline using GitHub Actions.

## Security Features:
- **Secret Scanning:** Detects hardcoded credentials.
- **SCA (Snyk):** Scans for vulnerable dependencies.
- **SAST:** Static analysis of the source code.

## Tools Used:
- GitHub Actions
- Snyk
- Gitleaks
